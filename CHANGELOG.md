# Changelog

Все значимые изменения в проекте AI-Органайзер документируются в этом файле.

## [Unreleased]

### Added (03.09.2026) - Русификация AI и редактирование

#### Русификация AI-промптов
- **Все AI-сервисы теперь генерируют текст на русском языке:**
  - `capture.py` — парсинг Magic Input (заголовки, описания, теги)
  - `decompose.py` — декомпозиция задач (шаги выполнения, подсказки)
  - `notes_ai.py` — анализ заметок (теги, резюме, форматирование)
  - `scheduler.py` — предложения по переносу просроченных задач
  - `digest.py` — вечерний дайджест (уже был на русском)

#### Редактирование задач
- Новый компонент `EditTaskDialog.jsx` для полноценного редактирования задач
- Возможность изменять:
  - Заголовок задачи
  - Описание
  - Дату и время выполнения
  - Категорию (тег)
  - Флаги "Срочная" и "Важная"
- Кнопка редактирования добавлена в `TaskItem.jsx`
- Обновлены `TaskList.jsx` и `App.jsx` для обработки изменений

#### Inline-редактирование шагов чек-листа
- Реализован режим редактирования шагов прямо в `ChecklistDialog.jsx`
- Редактирование без дополнительных диалоговых окон
- Поддержка горячих клавиш:
  - `Enter` — сохранить изменения
  - `Escape` — отменить редактирование
- Визуальные кнопки сохранения (✓) и отмены (✕)

#### Обновления компонентов
- `TaskItem.jsx`:
  - Добавлена кнопка редактирования (✏️)
  - Импорт `EditTaskDialog`
  - Обработчик `handleTaskUpdated`
- `TaskList.jsx`:
  - Добавлен проп `onUpdate` для обновления задач
- `App.jsx`:
  - Добавлен обработчик `handleUpdateTask`
- `ChecklistDialog.jsx`:
  - Добавлены стейты для inline-редактирования
  - Обработчики `handleStartEdit`, `handleCancelEdit`, `handleSaveEdit`

#### Качество кода
- Все изменения прошли проверку линтерами:
  - Backend: `ruff check`, `black`, `isort` — без ошибок
  - Frontend: `eslint`, `prettier` — без ошибок

### Added (03.09.2026) - Docker и персистентность данных

#### Исправление персистентности
- Изменён путь к БД: `backend/data/ai_organizer.db`
- Добавлены скрипты резервного копирования:
  - `backup_db.py` — Python-скрипт
  - `backup_db.bat` — Windows-обёртка
  - `backup_db.sh` — Linux/macOS-обёртка
- Автоматическая ротация старых копий (хранение последних 10, удаление > 30 дней)

#### Исправление HMR в Docker
- Добавлена HMR конфигурация в `vite.config.js`:
  - `hmr: { clientPort: 5173, host: 'localhost' }`
  - `watch: { usePolling: true }`
- Упрощен `frontend/Dockerfile`: убран дублирующий `--host` флаг

## [1.0.0] - Первый релиз

### Основной функционал

#### Backend (FastAPI + SQLite)
- REST API для задач, заметок, планировщика и дайджеста
- Модели данных: Task, ChecklistItem, Note, NoteChunk
- Интеграция с OpenAI (Chat + Embeddings)
- Логирование, обработка ошибок, CORS

#### Frontend (React + MUI + Vite)
- Magic Input для умного создания задач
- Список задач с чек-боксами и приоритетами
- Декомпозиция задач на шаги через AI
- Заметки с автотегированием
- Семантический поиск по заметкам
- Планировщик с матрицей Эйзенхауэра
- Вечерний AI-дайджест

#### AI-возможности
- Парсинг естественного языка для создания задач
- Автоматическая декомпозиция задач на шаги
- Автотегирование заметок
- Семантический поиск с эмбеддингами
- Быстрое форматирование текста
- Умный перенос просроченных задач
- Аналитика продуктивности

#### Docker
- Контейнеризация backend и frontend
- Dev-режим с hot-reload
- Production-режим с nginx
- Docker Compose для оркестрации

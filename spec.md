# Спецификация приложения "AI-органайзер" (AI Organizer).

Необходимо разработать простое веб-приложение "AI-органайзер" (с интеллектуальными чек-листами, заметками и планировщиком).

## Описание функционала

### 1. Умный ввод и распознавание (AI Capture)

Главная задача интерфейса — свести к нулю количество кликов для создания задачи.

**Единая строка ввода (Magic Input):** Пользователь пишет запрос в свободной форме (например: «Напомни созвониться с Олегом по поводу договора в этот четверг в 14:00»).

**Автоматический парсинг (NLP):** ИИ сам извлекает из текста суть, дату, время, категорию (тег) и создает задачу.

### 2. Динамические чек-листы (AI Todo & Decomposing)

Рядом с любой крупной задачей (например, «Подготовиться к презентации») есть кнопка «Разбить на шаги». 

ИИ генерирует пошаговый чек-лист (Например: 1. Собрать аналитику, 2. Сделать структуру слайдов, 3. Написать текст...).

**Контекстные подсказки:** ИИ оценивает сложность задачи и предлагает добавить сопутствующие подзадачи, о которых пользователь мог забыть.

### 3. Интеллектуальные заметки (AI Notes & Smart Wiki)

**Авто-тегирование и связи:** ИИ анализирует текст новой заметки, автоматически присваивает теги и предлагает связать её с существующими задачами или проектами.

**Функция "Спроси свои заметки" (Semantic Search):** Полнотекстовый поиск на базе ИИ. Можно спросить: «Что я думал по поводу подарка маме месяц назад?», и приложение найдет нужный абзац, даже если там нет точного совпадения слов.

**Быстрое форматирование:** Выделение текста позволяет мгновенно сделать из него краткую выжимку (summary), исправить грамматику или изменить тон (сделать более деловым/дружелюбным).

### 4. Адаптивный планировщик (AI Scheduling)

Органайзер помогает не просто записывать дела, но и находить для них время.

**Авто-расстановка приоритетов:** На основе матрицы Эйзенхауэра или дедлайнов ИИ подсвечивает фокус-задачи на день.

**Мягкие дедлайны (Smart Rescheduling):** Если задача просрочена, ИИ не просто переносит её на завтра, а анализирует загруженность дня и предлагает оптимальное «окно» в расписании.

### 5. Итоги дня и мотивация (AI Insights)

Приложение работает как персональный коуч.

**Вечерний дайджест:** Короткий ИИ-отчет в конце дня: «Сегодня вы выполнили 80% задач. Самым продуктивным временем было утро. Завтра вас ждет сложный созвон, рекомендуем разгрузить первую половину дня».

## Базовый интерфейс и технологии

- **Базовый функционал**:  
  - поле для ввода задачи,  
  - кнопка «Добавить»,  
  - список с задачами,  
  - кнопка «Удалить» или «Очистить список»,
  - кнопка «Разбить на шаги»,
  - история задач в `localStorage`.
- **npm-скрипты**:  
  - `npm run dev` — запуск dev-сервера,  
  - `npm run build` — сборка проекта,  
  - `npm run preview` — проверка сборки.
- **Технологии:**
  - Python;
  - HTML + CSS + JavaScript;
  - Node.js + npm;
  - React + Material UI (компоненты кнопки/списка);
  - OpenAI;
  - SQLite.
- Использование линтера и форматтер (ESLint/Prettier). 
- **README.md**: что за проект, как запустить, как собрать.
